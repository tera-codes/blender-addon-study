# blender-addon-study

A learning repository for studying Blender add-on development.

This is **not** a collection of my original work.
Code in this repository is transcribed from existing open-source add-ons
for the purpose of understanding the Blender Python API (bpy).
Each folder contains a README with the original author, source link, and license.

Study notes are written in Japanese.

## Rules

- Only add-ons with an explicit GPL-compatible license are included as code.
- Add-ons without a stated license are studied locally; only notes are published.
- All transcribed code retains the original author's credit.
